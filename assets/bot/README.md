# Caelis Bot logo

`caelis-bot-logo.png` is the exact 1254 × 1254 transparent PNG supplied and selected by the project owner on 2026-09-23 for the website's Caelis Bot identity.

The build creates 96, 256, and 512 pixel WebP derivatives without changing the artwork. The original is retained here. Product pages and social images use this asset; the Caelis Labs vector identity remains separate.
