# Implementation direction

Visual thesis: a quiet observatory for open agent tools, with spacious graphite and warm-white surfaces, crisp typography, an indigo accent, and the existing living sky.

Content plan: a concise Labs introduction, a large Caelis demonstration, a warmer Bot feature, ordered developer-project rows, then a clear documentation invitation. Product detail pages lead into installation and useful guides. Documentation has its own calm reading layout.

Interaction thesis: gentle constellation parallax and occasional meteors; a restrained entrance and scroll focus on the real Caelis recording; small directional link and navigation transitions. Respect reduced motion, stop animation outside the viewport, and keep content available without JavaScript.

Implementation follows the user's instruction to build on the existing site. The current site is the visual reference; its stellar background, theme behavior, and real demonstration are retained. The selected implementation direction is the recommended Orbit C vector identity. No generated bitmap is used as the navigation logo.

Project order: Caelis, Caelis Bot, ACP Go SDK, Memory, Caelis App. All project lists derive from one ordered data source.

No commit, push, or deployment is part of this local implementation pass.
