ACP Go SDK 是产品中立、由社区维护的 Go SDK。可用于实现智能体，也可以将客户端连接到本地智能体进程。

## 从这里开始

1. [安装 Go 模块](./quickstart/)。
2. 运行[最小 Agent](./agent/) 与 [Client](./client/)。
3. 使用可选协议能力前，阅读[兼容约定](./compatibility/)。

示例智能体返回固定问候语。运行该示例不需要模型账号、API Key、Node.js 或 Rust。

## API 参考

Go 符号级 API 见 [pkg.go.dev](https://pkg.go.dev/github.com/caelis-labs/acp-go-sdk)。SDK 可以独立于 Caelis 或其他智能体框架使用。
