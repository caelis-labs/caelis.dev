Caelis Bot 将一个生动的小角色带到桌面。你可以寻求帮助、分享文件，并在需要时审批操作。

## 当前正式版

- 适用于 Apple Silicon Mac。
- 需要单独安装并配置的本地 Caelis 或 Codex 运行时。
- 支持英文和简体中文，可在设置中切换。
- 自动检查更新，由你确认下载与安装；从 v0.1.0 升级需先手动安装一次。

[下载 macOS 版](/download/caelis-bot/) · [SHA-256](/download/caelis-bot/?asset=checksum) · [GitHub Releases](https://github.com/caelis-labs/caelis-bot/releases/latest)

先阅读[安装与首次启动](./installation/)，再了解[对话操作](./conversation/)。

## 独立的桌面产品

Caelis Bot 指 `caelis-bot` 仓库中的桌面应用。Caelis 与 Codex 是独立安装的运行时，桌面应用不捆绑它们。

代码使用 Apache-2.0。内置角色与头像采用独立的[角色资产许可](https://github.com/caelis-labs/caelis-bot/blob/e58d90b7c26f1f004d25d05d9b55fed6973482b3/ASSET-LICENSE.md)。
