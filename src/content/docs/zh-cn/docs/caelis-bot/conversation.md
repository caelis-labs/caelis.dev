## 打开对话

单击角色打开或隐藏聊天，双击唤回聊天及已打开的设置。草稿保留在聊天窗口。macOS 菜单栏和 Windows 系统托盘提供设置、显示隐藏与退出入口。

发送消息或附上文件，回复会回到持续的对话中。遇到需要你决定的操作，先核对请求再确认继续。

## 选择对话与工作模型

打开**设置 → 连接与模型**。对话模型用于与你交流，默认工作模型用于新委派的任务，两者可以分别选择。已有工作继续使用原连接。可选模型、推理选项和图片能力取决于已连接的服务。

桌面安装包已内置 Caelis，用于连接模型服务；Codex 使用你自己的本机安装和账号。更换 Runtime 与选择另一个模型不同，请按应用中的连接引导操作。

## 跟进较长的工作

Bot 可以委派代码、研究或文档任务。打开角色旁的任务入口，查看进展和完成结果。任务卡片可以打开关联的外部终端以便观察；关闭观察终端不会停止后台工作。是否完成以实际结果为准，角色动画只负责表达状态。

macOS 的**远程机器**支持配置 SSH 机器，为其单独登录 Runtime 并选择默认工作模型，再在对话中明确指定使用哪台机器。账号和文件不会自动复制，也不会自动分配到远端。

## 只分享你选中的画面

在**设置 → 附加功能**开启截图和贴图。按 **F1** 选择区域、标注或脱敏，检查后再复制、保存或发送。当前模型明确支持图片时，才可使用**问 Bot**；复制、标注和贴图不要求图片模型。**F3** 将剪贴板图片贴在桌面上。

所需系统权限在实际使用时申请。手动截图不是持续录屏；电脑操作插件是另一项能力，可能使用前台窗口、鼠标和键盘。

## 笔记、提醒与连接服务

Notebook 保存可由你和 Bot 阅读、修改的 Markdown 笔记。告诉它需要记住哪些偏好或项目事实；笔记不是模型训练，其内容由你掌握。

可以在对话中安排提醒。调度要求应用保持运行，并受休眠、锁屏和通知权限影响，不是持续在线的云端闹钟。

在设置中添加支持的插件，通过**消息渠道**连接 Telegram，继续同一个 Bot 对话。各服务的账号、权限和可执行操作各不相同，请按需分享信息。

## 腾出桌面空间

可以移动、缩放或隐藏角色。关闭聊天或设置不会退出，隐藏角色不会取消工作。选择**退出**才会结束应用并暂停常驻提醒。连接或功能不可用时，请看[常见问题](../troubleshooting/)。
