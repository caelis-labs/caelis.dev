ACP Go SDK is a product-neutral, community-maintained SDK. Use it to implement an agent or connect a client to a local agent process.

## Start here

1. [Install the Go module](./quickstart/).
2. Run the [minimal agent](./agent/) and [client](./client/).
3. Read the [compatibility contract](./compatibility/) before adopting optional protocol features.

The sample agent returns a fixed greeting. You can run the example without a model account, API key, Node.js, or Rust.

## Reference

Use [pkg.go.dev](https://pkg.go.dev/github.com/caelis-labs/acp-go-sdk@v1.4.0) for Go symbols. The SDK can be used independently of Caelis or any particular agent framework.
