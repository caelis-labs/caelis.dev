## Open the conversation

Click the desktop character to write. Double-click to open the conversation. The menu-bar home provides settings and Quit.

## Work together

Send a message or attach a file to provide context. Replies stream into the ongoing conversation. When an action needs approval, review it before allowing the agent to continue.

Conversation capabilities depend on the installed runtime. The public preview uses your local Codex runtime; configure it in **Settings → Runtime** if automatic discovery does not find it.

## Make room

Move or resize the character, or hide it temporarily. Hiding the character does not stop work. Use the menu bar to bring the application controls back into view.

For installation requirements and current limits, see [troubleshooting](../troubleshooting/).
