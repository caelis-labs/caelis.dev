Caelis Bot puts a small, expressive character on your desktop. Ask for help, share a file, and review actions when approval is needed.

## The current preview

- macOS on Apple Silicon.
- A separately installed, signed-in local Codex runtime.
- Manual updates; preview builds use an ad-hoc signature and are not notarized.

Start with [installation and first launch](./installation/), then learn the [conversation controls](./conversation/).

## A separate desktop product

Caelis Bot is the desktop application in the `caelis-bot` repository. The `caelis bot` command is a different terminal surface in the main Caelis project.

Code uses Apache-2.0. The bundled character and avatar use the separate [character asset license](https://github.com/caelis-labs/caelis-bot/blob/0842c59ac7ab007b67f7d25a51129b87d37bd60e/ASSET-LICENSE.md).
